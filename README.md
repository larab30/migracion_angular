# Presentacion de Dante (Angular)

Tarjeta de presentacion de **Dante Kaleb Rodriguez Flores**, migrada de HTML/CSS a Angular 21 con estetica grunge.

## Requisitos

- Node.js 20.19+, 22.12+ o 24+

## Uso

```bash
npm install
npm start
```

Abre `http://localhost:4200/`.

## Estructura

- `src/app/dante.ts` – datos de la presentacion
- `src/app/app.*` – tarjeta principal (efecto de maquina de escribir con signals)
- `src/app/guitarras/` – guitarras flotantes del fondo
- `src/styles.css` – fondo, grano y lineas de escaneo
- `public/fondo.jpg` – imagen de fondo

## Build

```bash
npm run build
```
